# API de Gerenciamento de Produtos

Projeto desenvolvido utilizando Java e Spring Boot 2.7.18 para gerenciamento de produtos por meio de uma API REST.

## Tecnologias utilizadas

- Java 21
- Spring Boot 2.7.18
- Spring Web
- Spring Data JPA
- Banco de dados H2
- Maven

## Funcionalidades

- Cadastrar produtos (POST)
- Listar produtos (GET)
- Buscar produto por ID (GET)
- Atualizar produtos (PUT)
- Excluir produtos (DELETE)

## Estrutura dos produtos

Cada produto possui:
- ID
- Nome
- Descrição
- Preço
- Quantidade
## Endpoint principal

`/api/produtos`

## Banco de dados

O projeto utiliza o banco H2 em memória, integrado ao Spring Data JPA.

## Como executar

Execute os comandos:

```bash
mvn clean test
mvn spring-boot:run
```
